# Changelog

## 0.2.1

- Added cosmetic jumps during normal exploration using the game's native jump animation.
- Added stationary and eight-direction visual jump support.
- Kept the player root, collider, navigation state, and traversal permissions unchanged.
- Made native interactions and movement transitions take priority over cosmetic jumps.
- Restored the appropriate idle, walk, or run animation after every cosmetic jump.
- Added a native-styled, shared Mods tab with localized settings for every supported game language.
- Added an enable toggle and a native segmented duration slider limited to 0.3–0.6 seconds.
